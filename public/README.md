# 🚑 منصة الجنوب - إدارة العمليات الإسعافية

نظام متكامل لإدارة العمليات الإسعافية في قطاع جنوب الرياض.

## ✨ الميزات

- 📊 إدارة البلاغات الإسعافية
- 📋 المناوبات وتكميل النوبة
- 🚨 نظام وقت الذروة مع معاينة الخريطة
- 🎨 ثيمات وخلفيات مخصصة
- 🚁 الإسعاف الجوي
- 📈 إحصائيات احترافية
- 📱 متجاوب مع جميع الأجهزة

## 🛠️ التقنيات المستخدمة

- Node.js + Express
- MongoDB Atlas
- HTML + CSS + JavaScript
- Leaflet.js (الخرائط)
- Font Awesome (الأيقونات)
