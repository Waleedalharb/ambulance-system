# 🏥 منصة الجنوب

نظام إدارة العمليات الإسعافية - قطاع جنوب الرياض

---

## 📋 عن النظام

منصة متكاملة لإدارة البلاغات الإسعافية، توزيع الفرق، وتسجيل المناوبات مع:

### ✅ الميزات الرئيسية

- **تسجيل البلاغات** مع الوقت والتاريخ
- **نظام المناوبات** (صباحية / ليلية)
- **مؤشرات القوى العاملة** والجاهزية
- **إحصائيات فورية** للبلاغات
- **أرشيف المناوبات** السابقة
- **نظام الإشعارات** وتوقيتات الذروة
- **التحديثات التشغيلية** (منتدى)
- **الإسعاف الجوي** مع إرسال واتساب
- **التحكم والتنسيق** مع إجازات الموظفين
- **كبار المسعفين** مع التوقيعات
- **الجدول الشهري** (Excel)
- **الثيمات** وخلفيات مخصصة
- **معاينة الخريطة** لمواقع الفرق
- **نظام وقت الذروة** مع خريطة تفاعلية
- **وضع الثيم** لعرض الخلفية فقط

---

## 🚀 التشغيل

### المتطلبات الأساسية
- Node.js (v16 أو أحدث)
- حساب على منصة Render (للاستضافة)
- حساب GitHub (لرفع الملفات)

### التثبيت المحلي (للتجربة)
```bash
# 1. استنساخ المشروع
git clone https://github.com/your-username/ambulance-system.git

# 2. الدخول إلى المجلد
cd ambulance-system

# 3. تثبيت التبعيات
npm install

# 4. تشغيل الخادم محلياً
npm start
